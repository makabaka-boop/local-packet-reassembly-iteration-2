# 本地小端 PCAP · TCP 重组查看器（限定版）

纯浏览器实现：读取**不超过 8 MB、2000 个包**的限定版经典 PCAP，**只解析小端 PCAP /
以太网（Ethernet II）/ IPv4 / TCP**，按双向四元组重组 TCP 字节流。文件**从不上传**，
全部解析在 Web Worker 内于本机完成。

## 运行

```bash
cd src
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

> 需经本地静态服务器打开（Web Worker 在 `file://` 下通常被禁止）。
> 可把 `samples/demo.pcap`（由 `node test/make-sample.js` 生成）直接拖入页面。

## 功能与保证

- **连接与方向**：按归一化双向四元组 `IP:port <-> IP:port` 归并；每个方向独立重组。
- **同四元组多会话拆分**：同一四元组被复用（先后多次 TCP 会话）时，按连接生命周期
  证据拆分为多个会话实例，各自独立重组，第二次会话的字节**不会**被误报为第一次的
  重传 / 冲突 / 缺口。拆分只依据序号与标志位事实，不猜测：
  - 新 SYN（不带 ACK）的 ISN 与本会话同方向已有 SYN 不同，或会话已越过纯 SYN 阶段
    （同 ISN 的 SYN 视为重传、双向 SYN 视为同时打开，均不拆）；
  - SYN+ACK 的 ISN 与本会话不符、且其 ack 未确认本会话的 SYN（对方 SYN 可能漏抓）；
  - 会话已关闭（任一方向 RST，或双向 FIN）后，序号不落在已覆盖区间内的包；
  - 本方向 FIN 之后又出现越过 FIN 序号位的数据（同一连接不可能）；
  - 数据序号落在本方向 ISN 之前（同一连接不可能）。
  迟到包（旧会话的重传 / 控制包）若当前会话解释不了、但某个更早会话能完整容纳，
  归回其来源会话，不污染新会话证据。**每个 TCP 包恰好归属一个会话**；拆分依据
  （触发的包号、ISN、关闭方式）随会话展示并写入导出头部。单向片段、缺握手、
  FIN/RST 关闭、序号回绕、两会话间夹杂其他连接等情形均适用同一套规则。
- **重传去重**：重叠位置字节完全相同 => 计为重传并去重，不重复计数。
- **缺口显式留空**：缺失序号区间形成覆盖段（run）之间的 gap，文本中以
  `␠[缺口 N 字节]` 标注、十六进制视图中打印缺口行；**绝不**把缺口两侧内容直接拼接。
- **字节冲突**：重叠位置字节不一致 => 标记冲突，展示保留“文件中先捕获”的字节，
  并在冲突面板列出每个到达包的包号与实际字节。不凭到达顺序悄悄覆盖。
- **32 位序号回绕**：以每方向锚点（优先首个 SYN 的 ISN，否则首个数据段 seq）展开序号；
  按捕获顺序用“最高字节水位（段尾）”解包，正确处理回绕点附近的乱序 / 重传 / 缺口；
  回绕事件在“异常”面板显式说明。真实跨度达到 2^31（8MB 文件内不可能）会标记歧义，不猜测。
- **限定版 HTTP/1.1 报文视图（取证不拼造）**：在每个方向、每个会话内单独识别。
  只在**同一覆盖 run（缺口之间的连续字节段）内、且无字节冲突**的字节上识别合法
  起始行（`request-line` / `status-line`，仅 HTTP/1.1）、逐条 CRLF 头部与空行
  结束的头部块，并按**明确的 `Content-Length`**确定消息体；每条报文给出：
  - 该报文在该方向流中的展开字节区间 `[start,end)` 与相对序号区间；
  - **逐字节归属包号合并出的证据段**（这些字节确实来自哪些捕获包、各占哪个区间），
    相同字节重传作为旁证包号列出（不改变内容）；
  - 三态结论：**完整 / 未完成 / 不支持**。
  - 起始行或头部在 run 边界被截断、头部块不完整、`Content-Length` 非法（非数字、
    多个取值不一致、逗号列表、超界）、CL 声称长度越过连续覆盖区（**跨缺口**或捕获
    结束）等候选一律标为**未完成**，绝不把缺口两侧文本拼成伪完整报文；报文区间内
    只要存在**字节冲突**位置，即使语法完整也标未完成（内容不唯一）；
  - `Transfer-Encoding`（含 `chunked`）等未支持格式明确标为**不支持**，只引用到
    头部块结束，不猜测正文边界、也不向其后扫描流水线报文；
  - run 起点的杂散前缀只在“第一行内”做一次起始线再同步，跳过字节显式留痕
    （notice）；无法识别的起始线立即停止该 run，剩余字节标“未解析尾部”，不猜边界；
  - **同四元组的后续会话独立识别，绝不续接前一会话的残余报文**。
  识别结果与 run 字节、缺口、冲突、十六进制证据共用同一套字节事实；报文随
  冻结快照深拷贝并写入 JSON 导出。
- **页面视图**：按连接、方向查看 包 / 缺口 / 冲突 / HTTP 报文 / 重组文本 / 十六进制 / 异常；
  另有“未纳入重组的包”（非 IPv4、非 TCP、IP 分片、snaplen 截断等）列表。
- **导出引用冻结结果**：解析完成即对重组结果（含 HTTP 报文、全部字节、逐字节包号）
  深拷贝冻结。Worker 只回传这一份冻结快照，**页面选中项与 JSON 导出引用的是同一个
  快照对象**；“导出当前文本”同样从该快照读取，后续重新导入或任何操作都不会改变它。
  换文件 / 取消后旧 Worker 被 terminate、迟到结果按 token 丢弃，旧结果不能复活。
- **错误文件头整份拒绝**：魔数不是 `d4 c3 b2 a1`（含大端 pcap、pcapng）、
  链路层非以太网 => 致命错误，整份不展示。
- **截断包留证并停止**：记录头或记录数据在文件尾部被截断时，保留文件偏移、
  `incl_len/orig_len`、剩余字节数等位置证据，停止解析该包（此前包仍可见）。
- **旧 Worker 迟到结果不替换当前文件**：每次导入使用递增会话 token，并
  `terminate()` 旧 Worker；主线程丢弃 token 不匹配的迟到结果；“取消”同样令在途结果失效。

## 文件结构

```
src/
  index.html      页面
  styles.css
  app.js          UI、会话/token 管理、限制校验、冻结导出
  worker.js       Web Worker：本地解析 + 冻结
  pcap.js         小端 pcap / 以太网 / IPv4 / TCP 解析（UMD，Node 可复用）
  http.js         限定版 HTTP/1.1 报文识别（连续无冲突字节、CL 定界、
                  缺口/冲突/截断/长度异常标未完成、TE 只标不支持，UMD）
  reassemble.js   双向四元组归并与同四元组多会话拆分、序号展开与回绕、
                  去重/缺口/冲突、逐字节包号归属、HTTP 识别、冻结（UMD）
test/
  run-tests.js    Node 对拍测试（乱序/回绕/重传/缺口/冲突/截断/拒绝/会话拆分/
                  HTTP 跨包头部/重传/缺口/冲突/长度异常/TE/端口复用…）
  make-sample.js  生成 samples/demo.pcap
samples/demo.pcap 演示样本（生成物）
```

## 运行测试

```bash
node test/run-tests.js     # 对拍用例
node test/make-sample.js   # 重新生成演示样本
```

## 明确不做的事

- 不解析 pcapng、大端（字节交换）pcap、非以太网链路层。
- 不解析 IPv6、UDP 等非 TCP 协议；IP 分片不参与 TCP 重组。
- 不校验 TCP/IP 校验和（抓包常置零）；不做 TCP 状态机推断，只依据序号与字节事实重组。
- 同四元组复用缺少一切生命周期证据时（无新 SYN/SYN+ACK、无 FIN/RST 关闭、
  序号也不矛盾），不凭启发式猜测拆分会话：包留在当前会话，缺口/冲突照实展示。
- HTTP 仅识别 **HTTP/1.1**（不识别 HTTP/1.0 等版本起始线）；消息体只接受明确的
  单个非负 `Content-Length` 定界，不按连接关闭/流水线猜测长度；**不支持
  Transfer-Encoding（含 chunked）、Upgrade、TLS 解密、multipart 边界推断、
  CONNECT 隧道内容**——这些一律标“不支持”，不猜正文边界。
- 不把跨缺口、含冲突、截断或长度不完整的候选当作完整报文输出；缺口另一侧的
  合法起始线只在其自己的连续段内独立识别，不与前一条续接。
